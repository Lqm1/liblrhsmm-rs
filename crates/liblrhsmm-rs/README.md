# liblrhsmm-rs

The native Rust library for [liblrhsmm-rs](https://github.com/Lqm1/liblrhsmm-rs).
It is a modern Rust reimplementation preserving the upstream data formats and
computational behavior. See the repository README for compatibility reports,
examples, public API coverage and native host requirements.

## Installation

```console
cargo add liblrhsmm-rs
```

Only this core crate is published to crates.io. Node.js, Python, WebAssembly
and C bindings are distributed separately from the same release commit.
Source, regression fixtures and tests are available in the tagged repository.
