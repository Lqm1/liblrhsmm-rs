# liblrhsmm-rs

An idiomatic Rust reimplementation of the complete public liblrhsmm functionality, licensed under GPL-3.0-or-later. Upstream: https://github.com/Sleepwalking/liblrhsmm.

The port is in progress. Owned model/data containers and model, standalone duration/GMM/stream, observation, segmentation, and dataset serialization are implemented. Flat-start model/stream constructors and incremental builders preserve C defaults; unfilled builder slots are rejected before use. Owned clones preserve GMM variance floors and independent segmentation storage. Model operations include single-component concatenation, duration conversion, highest-weight mixture splitting, and weighted duration log density. Prepared GMM likelihoods and weighted multistream log-density and density tables support the original boundary and diagonal pruning conventions. Annealed duration log densities and densities are exposed directly. Non-log tables have a separate type so they cannot be passed accidentally as log scores. Geometric-duration HMM forward/backward and Viterbi are implemented with the original quantized probability helpers. Explicit-duration HSMM forward and Viterbi support skip, self, and backward transitions through an immutable transition graph. HSMM backward and geometric HMM state/transition occupancies are implemented. HSMM duration/state occupancies and HSMM/HMM mixture occupancies are implemented, including the documented initial-state correction. Owned sufficient statistics, aligned initialization collection, and duration/GMM/stream/model maximization updates are implemented. HSMM and geometric HMM posterior expectation collection and single-utterance estimation are implemented. Synthetic tests connect two expectation/update iterations to saving, reloading, and inference. Aligned dataset regrouping and Viterbi path resegmentation are implemented. Model generation supports caller-owned RNGs and controlled uniform draws, preserving the original normal approximation and mixture selection. SHIRO integration exercises initialization, HMM/HSMM training, saving, reloading and inference. Binary64 model storage, densities, preparation, inference, posteriors, statistics and training are implemented; dataset regrouping, resegmentation and sample builders also retain binary64 precision. Generation and wire codecs still require binary64 support. Complete public configuration and numerical audits remain in progress. See `docs/api-inventory.csv` for the initial source inventory; it still requires review of macros, configuration values, and ownership equivalents.

cargo test --target i686-pc-windows-msvc

The model reader supports the historical GMM format used by SHIRO's pretrained model and the current format with per-dimension variance floors. The default writer produces the current C-readable format. `ModelEncoding::WithoutVarianceFloors` explicitly writes historical models and rejects nonzero variance floors rather than losing data.

The complete native acceptance gate requires Windows and Linux x86 32-bit and 64-bit execution tests, including the Tier 1 Windows x86_64 GNU target, before C ABI and WebAssembly implementation. Those bindings are not implemented yet.

Sampling API references: https://docs.rs/rand/0.10.3/rand/trait.RngExt.html and https://docs.rs/rand/0.10.3/rand/distr/struct.OpenClosed01.html. Callers provide the RNG, so the library does not enable sys_rng or thread_rng. SmallRng and StdRng do not promise reproducible sequences across versions or targets; controlled uniform draws support explicit C comparisons.

MemoryPool provides append-only byte allocation with the original page growth and accounting. PoolAllocation handles keep regions addressable across growth; get/get_mut return borrowed slices and reject foreign handles. Exposed bytes are initialized, including allocate. Reference Rust APIs: https://doc.rust-lang.org/std/vec/struct.Vec.html#method.try_reserve_exact and https://doc.rust-lang.org/std/sync/struct.Arc.html#method.ptr_eq.

ObservationSetBuilder and SegmentationSetBuilder support ordered incremental dataset construction. Model::prepare returns a borrowed PreparedModel with reusable emission normalizers and duration caches; PreparationOptions controls cache length, duration weight, and temperature. PreparedModel evaluates emission tables and runs HSMM forward/backward/Viterbi inference using these caches. Prepared inference requires matching temperature and duration weight. State and boundary pruning support fractional binary32 radii with the original C bounds. Remaining header/build configuration coverage is tracked in docs/configuration-coverage.md.
